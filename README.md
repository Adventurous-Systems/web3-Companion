# web3 Companion

This website has been developed as a companion to becoming a blockchain/web3 developer on Ethereum, with a focus on uses in architecture, engineering and construction (AEC). It is designed as a series of structured links and notes that, when followed, give you the basic knowledge to develop decentralised applications. Plan on two to four months: the [syllabus](syllabus.md) lays out a 12-week path of roughly eight weeks of reading and practice followed by four weeks on a project.

Read the companion here: [adventurous-systems.github.io/web3-Companion](https://adventurous-systems.github.io/web3-Companion/)

## Maintaining

- The site is built by GitHub Pages (Jekyll, `jekyll-theme-minimal`) from the `gh-pages` branch.
- A GitHub Action checks every link on each pull request and once a week, and opens an issue when links break. Links that block automated checkers are listed in `.lycheeignore`.
- When you add a resource, prefer official documentation over blog posts, and add a note if a tool is deprecated rather than deleting it silently (see the "Deprecated and archived" table in the companion).
